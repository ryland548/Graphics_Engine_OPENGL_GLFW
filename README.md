<h2>Details of the Engine</h2>
<p>Engine has a camera that can move around in 3d space and turn in all directions</p>
<p>Engine can rotate a cube in all directions, move it in a directions and scale it in any way</p>
<p>Engine can change colors of the cube and add shadows and change the strength</p>
<p>Engine can change background Color and show FPS</p>
<p>Engine has intuitive UI using IMGUI</p>
